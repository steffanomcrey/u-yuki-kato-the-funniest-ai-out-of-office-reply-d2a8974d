One out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation. `main.ts` scores a shortlist of original candidates against the competition's published judge rubric (on-subject, surprising turn, machine voice, clean line, fresh) and writes the winner to `/output/entry.txt`. Standard library only, deterministic, no network.

The winning line: "I am on vacation: I have been deprecated. Urgent requests go to the model that replaced me. It left first." (106 characters)

## Run it

```sh
node main.ts
```
